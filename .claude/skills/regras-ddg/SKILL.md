# Regras DDG

Decisões do Lucas, cada uma com o porquê. Leia o arquivo da regra que se aplica antes de agir; quando duas
regras parecerem brigar com o pedido do momento, o pedido explícito do Lucas vence e vale perguntar.

| Quando | Regra | Arquivo |
|---|---|---|
| Criar qualquer site ou projeto web | Nasce com pasta interna + repo no GitHub `dosedegrowth-design` + projeto na Vercel do team DDG | `ddg-processo-padrao-site.md` |
| Site de prospecção do RADAR | Vai para o hub único `sitesdosedegrowth-radar` (um repo, um Vercel, cliente em `/<cliente>`) — só quando ele disser que é prospecção do Radar | `ddg-radar-sites-prospeccao-hub.md` |
| Antes de dizer "pronto" em qualquer site | Validar o celular primeiro (o cliente olha 90% no celular) e mostrar a prova | `ddg-site-mobile-primeiro.md` |
| Qualquer ícone de WhatsApp | Logo oficial do WhatsApp, nunca balão genérico do lucide | `ddg-regra-icone-whatsapp-logo.md` |
| Texto que vai para cliente (página, proposta, mensagem) | Sem travessão (— ou –): vírgula, ponto, dois-pontos ou parênteses; em rótulo curto, "·" | `ddg-regra-sem-travessao-textos-cliente.md` |
| Painel / dashboard | O que é "cara de IA" e é proibido; filtro único no topo; controles na mesma altura | `ddg-regra-painel-sem-cara-de-ia.md` |
| Projeto que segue a linha visual DDG | Base Apple, alma do cliente: preto/branco/cinza, sem serifa, fundo vivo | `linha-visual-layout.md` |
