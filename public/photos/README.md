# Fotos reais da Tayssa (@1.tayssa)

Coloque aqui as fotos reais, com estes nomes. Enquanto um arquivo não existe,
o site mostra um campo tonal no lugar (nunca imagem sintética). Trocar a foto
é só trocar o arquivo. Nada de HDR, nitidez artificial ou "melhoria" por IA.
