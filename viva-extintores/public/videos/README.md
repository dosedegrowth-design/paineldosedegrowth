# Vídeos dos casos reais

Arquivos `.mp4` referenciados em `lib/casos.ts` (campo `video`, com
`videoTipo: "arquivo"`). Para vídeo hospedado no YouTube, use o ID do
vídeo e `videoTipo: "youtube"` — aí nada precisa entrar nesta pasta.

Recomendado: H.264, no máximo ~1080p e ~8 MB por arquivo, para a página
continuar rápida no celular.
